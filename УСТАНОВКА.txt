ОБНОВЛЁННЫЙ TELEGRAM-БОТ: ВЛОЖЕННЫЕ МЕНЮ И ФОТО

Возможности:
- вложенные разделы и кнопки;
- текстовые ответы, ссылки и фотографии с подписью;
- управление через /admin;
- сохранение кнопок в SQLite;
- сохранена проверка подписки на публичный канал;
- настройки токена и ID администратора можно задавать переменными окружения.

ВАЖНО ПРО КНОПКИ TELEGRAM
Telegram Bot API не позволяет задавать произвольный цвет inline-кнопок или помещать изображение внутрь самой кнопки. Вместо этого бот отправляет фотографию с подписью, а кнопки размещает под сообщением.

НАСТРОЙКА
Установи Python 3.10+ и выполни:
  python -m pip install -r requirements.txt

Задай параметры через переменные окружения:
  BOT_TOKEN = токен от @BotFather
  CHANNEL_URL = https://t.me/имя_публичного_канала
  ADMIN_ID = твой числовой Telegram ID

Локальный запуск (пример PowerShell):
  $env:BOT_TOKEN="токен"
  $env:CHANNEL_URL="https://t.me/имя_канала"
  $env:ADMIN_ID="123456789"
  python main.py

В Linux shell:
  export BOT_TOKEN="токен"
  export CHANNEL_URL="https://t.me/имя_канала"
  export ADMIN_ID="123456789"
  python main.py

КАК ДОБАВЛЯТЬ КНОПКИ
1. Отправь /admin.
2. Нажми «Добавить кнопку/раздел» и введи название.
3. Выбери, куда добавить кнопку: в главное меню или внутрь существующего раздела.
4. Выбери тип: раздел, текст, ссылка или фото.
5. Для фото отправь фотографию одним сообщением; подпись можно добавить к фотографии.
6. Чтобы добавить кнопки внутрь раздела, снова выбери добавление кнопки и укажи этот раздел в качестве родителя.

ХОСТИНГ 24/7
Для круглосуточной работы нужен VPS/Linux-сервер или хостинг, который поддерживает постоянно работающий Python-процесс. Загрузи main.py и requirements.txt, установи зависимости и настрой переменные окружения в панели хостинга. Команда запуска: python main.py.
Убедись, что bot_data.db хранится на постоянном диске и не удаляется при перезапуске/переразмещении. Настрой автозапуск/перезапуск через systemd или механизм хостинга.
Не запускай одновременно две копии бота с одним токеном.

ПРОВЕРКА ПОДПИСКИ
Канал должен быть публичным. Добавь бота администратором канала, чтобы он мог проверять подписчиков.

БЕЗОПАСНОСТЬ
Не публикуй BOT_TOKEN и не отправляй его другим людям. Если токен раскрыт, перевыпусти его через @BotFather.
