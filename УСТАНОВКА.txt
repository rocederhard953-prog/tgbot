ПРОФЕССИОНАЛЬНЫЙ TELEGRAM-БОТ С МЕНЮ ССЫЛОК

Возможности:
- главное меню с настраиваемым фото и приветствием;
- вложенные разделы, текстовые ответы, фотокарточки;
- URL-кнопки открывают ссылку напрямую и не отправляют сообщение;
- добавление, редактирование, удаление и изменение порядка кнопок;
- предпросмотр меню;
- учёт пользователей, новые пользователи за день, клики по внутренним кнопкам;
- рассылка текста или фото с предпросмотром и подтверждением;
- запланированные рассылки по времени сервера, отмена запланированных сообщений;
- поддержка: пользователь отправляет обращение, администратор отвечает через бота;
- реферальная ссылка и счётчик регистраций;
- резервная копия SQLite и журнал действий;
- настройки сохраняются в SQLite и переживают перезапуск;
- миграция старой базы кнопок по возможности без потери данных;
- зависимости устанавливаются через .bat.

УСТАНОВКА НА WINDOWS
1. Установите Python 3.10+ с python.org и включите Add Python to PATH.
2. Распакуйте весь архив в отдельную папку.
3. Запустите УСТАНОВИТЬ_ЗАВИСИМОСТИ.bat.
4. В открывшемся .env заполните BOT_TOKEN и ADMIN_ID. CHANNEL_URL оставьте пустым, если проверка подписки не нужна, или укажите публичный канал.
5. Сохраните .env и запустите START_BOT.bat.
6. Напишите боту /start, а затем /admin.

АДМИН-ПАНЕЛЬ
- Фото меню: отправьте фотографию; /remove_photo удаляет фото.
- Приветствие: меняется из панели.
- Управление кнопками: добавить, изменить название/содержимое, менять порядок, удалить.
- Ссылка: выберите «Прямая URL-ссылка», затем отправьте URL http:// или https://.
- Рассылка: отправьте текст либо фото с подписью, проверьте предпросмотр и подтвердите.
- Планировщик: время вводится как YYYY-MM-DD HH:MM и трактуется во временной зоне компьютера/сервера, где запущен бот. Бот должен быть запущен в момент отправки.
- Резервная копия: отправляет файл базы администратору.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Telegram не сообщает боту о нажатии обычной URL-кнопки. Поэтому статистика показывает нажатия внутренних кнопок, а не точные клики по прямым URL. Для точной статистики внешних переходов нужен собственный redirect/analytics endpoint.
- Пользователь попадёт в рассылку после /start в этой версии. Telegram не позволяет боту первым написать человеку, который никогда не запускал бота.
- Массовая рассылка выполняется последовательно с небольшой паузой; очень большие аудитории лучше обслуживать очередью и контролировать лимиты Telegram.
- Для проверки подписки бот должен быть администратором публичного канала. CHANNEL_URL может быть пустым, чтобы отключить проверку.
- Не запускайте две копии с одним токеном одновременно.
- Не публикуйте .env: в нём секретный токен.
- Резервная копия содержит ID пользователей и настройки — храните её безопасно.
- Фото и настройки главного меню хранятся в SQLite как Telegram file_id.
